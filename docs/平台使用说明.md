## 1. 平台简介

AI 模拟面试平台用于开展岗位模拟面试、单题快练、简历制作、课程学习、
面试复盘和教学数据分析。

学生可以选择企业和岗位，与 AI 面试官进行文字或语音对话，并在结束后查看
综合得分、能力画像和逐题建议。教师和管理人员可以在授权范围内查看学生的
训练进度、面试记录和班级能力数据。校级管理员还可以维护组织、账号、企业
岗位、学习内容、随机题库和系统参数。

## 2. 使用前准备

### 2.1 推荐环境

- 推荐使用最新版 Chrome 或 Edge 浏览器。
- 标准模拟面试建议在桌面或笔记本电脑上进行。
- 使用语音功能时，需要允许浏览器访问麦克风。
- 使用视频和体态分析时，需要允许浏览器访问摄像头。
- 麦克风和摄像头功能建议通过 HTTPS 地址使用。
- 如果不方便授权麦克风，标准模拟面试仍可切换为文字输入。

平台地址由学校或系统管理员统一提供。本地部署的默认地址为：

```text
http://127.0.0.1:5001
```

### 2.2 账号说明

平台不开放学生自助注册。学生账号由校级管理员创建或通过 Excel 批量导入。

| 角色 | 主要权限范围 |
| --- | --- |
| 学生 | 本人的简历、学习进度、模拟面试、报告和班级榜单 |
| 教师 | 所属系部和班级内的学生及面试数据 |
| 系部负责人 | 所属系部内的班级、学生及面试数据 |
| 校级管理员 | 全校数据和全部系统管理功能 |

## 3. 登录、改密与退出

### 3.1 登录

1. 打开平台地址。
2. 在“账号”中输入管理员分配的用户名或学号账号。
3. 输入密码。
4. 单击“登录”。

学生登录后进入“面试大厅”；教师、系部负责人和校级管理员登录后进入
“数据驾驶舱”。

### 3.2 首次登录修改密码

通过批量导入或管理员重置得到的密码属于一次性初始密码。首次登录后，系统
会要求先修改密码，完成前不能访问其他页面。

新密码应满足以下要求：

- 至少 10 个字符；
- 与当前密码不同；
- 两次输入必须一致。

建议使用字母、数字和符号的组合，不要与其他网站共用密码。

### 3.3 退出登录

单击左侧导航栏底部用户信息旁的“退出登录”按钮。使用公共电脑时，结束操作
后务必退出账号，并关闭浏览器窗口。

### 3.4 无法登录

- 出现“账号或密码错误”：检查输入法、大小写和账号是否正确。
- 出现“账号已停用”：联系校级管理员重新启用账号。
- 忘记密码：联系校级管理员执行密码重置。
- 注册入口不可用属于正常状态，账号由学校统一管理。

## 4. 学生端使用说明

### 4.1 面试大厅

面试大厅显示以下信息：

- 累计完成的面试场次；
- 平均得分、历史最高分和最近成绩趋势；
- 最近的面试记录及报告状态；
- 当前面试冷却或待复盘提示；
- 尚未完成的可续接面试。

记录可能处于以下状态：

| 状态 | 含义 | 建议操作 |
| --- | --- | --- |
| 进行中 | 面试尚未结束 | 单击“继续面试” |
| 报告生成中 | 对话已结束，后台正在生成报告 | 稍候等待，页面会自动刷新状态 |
| 已完成 | 报告已生成 | 单击“查看报告” |
| 报告失败 | 后台任务未成功完成 | 单击“重试报告” |
| 已放弃或已过期 | 面试未正常完成 | 等待冷却结束后重新开始 |

### 4.2 智能简历中心

从左侧导航进入“智能简历中心”。

#### 维护基础档案

单击“维护档案”，填写姓名、求职意向、电话、邮箱、所在地和自我评价。
这些信息可以在新建简历时一键导入。

#### 新建和编辑简历

1. 单击“新建简历”。
2. 输入简历名称。
3. 根据需要勾选“一键导入基础档案”。
4. 单击“立即创建”。
5. 在简历卡片中单击“进入编辑器”。
6. 填写教育背景、工作或实习经历、项目经历、校园经历、获奖情况和技能。
7. 选择合适的模板和版面密度。
8. 单击“保存”，确认页面显示“已保存”。

每名学生最多可以创建 5 份简历。简历内容支持 AI 文案优化，但使用优化结果
前应自行核对事实，不能添加不存在的经历或成绩。

简历卡片右上角菜单支持：

- 下载或导出 PDF；
- 重命名；
- 删除简历。

删除操作不可撤销。正在用于历史面试的简历快照不会因之后修改简历而变化。

### 4.3 开始标准模拟面试

1. 回到“面试大厅”。
2. 单击“立即开始面试”。
3. 选择企业。
4. 选择该企业下的岗位，并阅读岗位详情。
5. 选择面试官风格。
6. 选择难度：
   - 新手模式：适合首次训练；
   - 标准模式：适合常规模拟；
   - 压力模式：适合进阶训练。
7. 选择是否递交已有简历。选择简历后，AI 会结合该简历提问；不选择则进行
   盲面。
8. 单击“开始模拟面试”。

面试创建成功后，系统会进入面试房间，并显示 AI 面试官的开场问题。

#### 回答问题

文字回答：

1. 在输入框中填写回答；
2. 单击“发送”，或按 Enter 键提交；
3. 等待 AI 面试官继续提问。

语音回答：

1. 单击输入区左侧的语音切换按钮；
2. 按住“按住说话”开始录音；
3. 松开按钮完成转写并发送；
4. 如无法录音，可切回文字模式继续。

开启视频功能时，右侧会显示本地摄像头预览。系统仅在提交回答时分析当前
画面，不进行连续视频上传。请保持头部位于画面中央，并尽量看向摄像头。

#### 刷新、离开和续接

- 未发送的文字草稿会在当前浏览器会话中临时保留。
- 刷新页面后，可以继续当前面试。
- 返回大厅时，系统会提示是否续接尚未完成的面试。
- 进行中的面试长时间没有活动会自动过期，具体时长由管理员配置。
- 主动放弃面试会触发一段冷却时间。

#### 结束面试

1. 完成足够的问题后，单击右上角“结束面试”。
2. 在确认框中确认结束。
3. 系统提交对话，并在后台生成报告。
4. 返回大厅等待报告状态变为“已完成”。

报告采用后台队列生成，结束面试后短时间内看到“报告生成中”属于正常现象。
不要连续重复单击结束按钮。

### 4.4 查看报告和复盘

可以从面试大厅的最近记录或左侧“历史记录”进入报告。

报告包括：

- 综合得分和面试官总评；
- 多维能力雷达；
- 完整对话记录；
- 对学生回答的逐句评价；
- 改进建议和参考回答；
- 面试岗位、难度和时间信息。

打开一份已完成报告即视为完成本次复盘。如果管理员启用了“强制复盘后才能
再面”，学生必须先查看上一份报告，才能开始新的面试。

初面或复面完成后，报告页可能显示“进入下一轮”：

- 初面之后进入复面，重点考查专业能力；
- 复面之后进入终面，重点考查综合素质；
- 每条进阶链最多三轮；
- 下一轮仍受冷却和复盘规则限制。

### 4.5 面试冷却规则

无法开始新面试时，面试大厅会显示原因：

- 存在进行中的面试：先继续或放弃原面试；
- 中途放弃冷却：等待倒计时结束；
- 完成面试冷却：等待规定时间；
- 要求先复盘：先打开上一份报告；
- 上一份报告仍在生成：等待报告完成。

默认冷却时长可能由管理员调整，以页面实际提示为准。

### 4.6 随机问题面试

随机问题面试用于单题快速练习，不需要先选择企业和岗位。

1. 在面试大厅单击“随机问题面试”。
2. 阅读系统随机抽取的问题。
3. 单击“开始语音”进行回答，也可以在文本框中手动补充或修改。
4. 如需体态分析，可单击“开启摄像头”。
5. 单击“结束回答并分析”。
6. 查看本题得分、针对性评价、改进建议和体态观察。
7. 单击“换一题”继续训练。

随机练习依赖 AI 服务。若分析失败，请保留已填写的回答并稍后重试。

### 4.7 知识充电站

从左侧导航进入“知识充电站”。

课程内容分为两类：

- 文章：阅读完成后单击“标记已读，下一课”；
- 测验：选择答案后单击“提交试卷”。

测验满分 100 分，达到 80 分视为通过。未通过的尝试会被记录，但可以立即
重新作答；通过后该章节计入学习进度。

### 4.8 能力雷达

能力雷达根据已完成面试的数据生成，主要包括：

- 综合战力和历史最佳成绩；
- 个人能力与班级平均水平对比；
- 多维能力雷达图；
- 成长轨迹和趋势预测；
- 智能推荐训练；
- AI 职业诊断报告。

首次使用没有数据时，需先完成至少一场标准模拟面试并等待报告生成。

### 4.9 班级风云榜

班级风云榜仅比较同班学生，提供三个榜单：

- 综合实力榜：按已完成面试的平均分排序；
- 巅峰时刻榜：按单场最高分排序；
- 勤奋之星榜：按已完成面试场次排序。

报告尚未完成的面试不会计入榜单。

### 4.10 历史记录

“历史记录”展示累计场次、平均分、最高分、成长曲线、岗位分布和详细记录。

学生可以：

- 查看已完成报告；
- 返回进行中的面试；
- 对失败的报告重新提交生成任务；
- 在满足条件后隐藏不再需要显示的记录。

“隐藏记录”不会直接删除底层业务数据。管理员可在管理端查看和恢复隐藏记录。

## 5. 教师和系部负责人使用说明

教师、系部负责人和管理员使用同一套教学管理界面，但可见数据范围不同：

- 教师：本人所属班级；
- 系部负责人：本人所属系部；
- 校级管理员：全校。

### 5.1 数据驾驶舱

数据驾驶舱提供：

- 已完成面试总数；
- 平均综合得分；
- 学生最高平均分；
- 最新面试记录；
- 优秀学生 Top 5；
- 学生名册、面试流水和能力画像快捷入口。

单击学生或面试记录，可以进入学生详情或报告页面。教师查看学生面试房间时
为只读模式，不能代替学生发送回答。

### 5.2 班级对比看板

班级对比看板用于横向分析：

- 各班级平均总分；
- 多维能力热力表；
- 高频薄弱题和不合格率；
- 参与统计的面试场次。

数据不足时，部分图表或薄弱题列表可能为空。

### 5.3 学生学情名册

名册支持按系部、班级、姓名和学号筛选，展示：

- 学生基本信息和账号状态；
- 已完成面试场次；
- 平均得分；
- 最近活跃时间；
- 学生详情入口。

校级管理员还可以在名册中重置密码、停用账号或重新启用账号。

### 5.4 学生详情与面试记录

进入学生详情后，可以查看该学生的平均成绩、累计场次、成长趋势和历次面试。
面试报告和对话记录仅供教学分析使用，不应向无关人员转发。

### 5.5 面试记录流水

面试记录流水按权限范围展示完成记录，并提供近 1 小时、24 小时、1 周、
1 个月、1 年和全部记录统计。

教师和系部负责人可以查看及隐藏授权范围内的记录。恢复隐藏记录仅限校级
管理员操作。隐藏前应确认该记录无须继续在常规列表中展示。

### 5.6 班级能力画像

能力画像汇总授权范围内学生的能力维度、优势和短板，用于制定教学计划。
画像基于已完成且已生成报告的面试，不应把单次 AI 评分作为唯一评价依据。

## 6. 校级管理员使用说明

### 6.1 组织与学生管理

建议按以下顺序初始化：

1. 新增系部；
2. 选择系部，批量创建班级；
3. 下载学生导入模板；
4. 按模板填写学生信息；
5. 单击“批量导入学生”并上传 Excel；
6. 保存系统生成的一次性初始密码 CSV；
7. 通过安全渠道分别发放账号和初始密码。

注意事项：

- 如果导入文件中的班级不存在，系统会自动在对应系部下创建；
- 有学生的班级不能删除；
- 有学生的系部不能删除；
- 重置密码后，学生下次登录必须修改密码；
- 停用账号不会删除其简历、面试和学习记录；
- 一次性密码文件属于敏感数据，不应发送到公共群聊或公开网盘。

### 6.2 企业与岗位管理

1. 单击“新增公司”，填写公司名称和公司介绍。
2. 选择公司。
3. 单击“新增岗位”，填写岗位名称和岗位要求。
4. 保存后，该岗位会出现在学生的面试创建窗口中。

公司介绍和岗位要求支持 Markdown。岗位内容对学生可见，同时会作为 AI
面试官的背景信息，因此应准确、简洁，不要写入密钥、内部账号或其他敏感信息。

删除公司会同时影响其岗位配置。存在业务记录时，应优先保留或修改配置，
避免造成历史数据理解困难。

### 6.3 课程内容管理

管理员可以：

- 新增和删除课程分类；
- 在分类中添加文章；
- 在分类中添加测验；
- 删除尚未产生学习记录的内容。

文章内容支持 HTML。测验内容使用 JSON 题目格式，建议先单击“填入示例模板”
再按模板修改。保存前应检查 JSON 格式、选项和正确答案。

已有学习进度或答题记录的材料不能删除，以免破坏历史数据。

### 6.4 随机问题题库

进入“随机问题题库”，每行填写一个问题，完成后单击“保存题库配置”。

- 空行会自动忽略；
- 保存前应删除重复题；
- 问题应清楚、具体，避免包含学生隐私；
- 学生端每次会从当前题库随机抽取一题。

### 6.5 学生简历预览

管理员可以按姓名、学号、简历标题、班级或系部搜索学生简历，并执行只读
预览、打印或导出 PDF。管理端不提供编辑和删除学生简历的权限。

### 6.6 面试记录管理

校级管理员可以：

- 查看全校已完成面试；
- 打开学生报告；
- 隐藏不需要在常规列表中显示的记录；
- 切换到“查看已隐藏记录”；
- 恢复被隐藏的记录。

隐藏属于软删除，记录和对话仍保留。涉及异常数据处理时，应先记录原因，
再执行隐藏操作。

### 6.7 系统设置

系统设置包括：

- AI 语音输出开关；
- 视频面试和视觉分析开关；
- TTS 音频保留天数；
- 临时文件保留小时数；
- 进行中会话保留时长；
- 中途放弃后的冷却时长；
- 完成面试后的冷却时长；
- 是否强制查看上次报告后才能再次面试。

修改设置会影响全部用户。调整冷却时间或存储策略前，应先通知教师和学生。

## 7. 常见问题

### 7.1 麦克风或摄像头无法使用

1. 检查浏览器地址栏旁的权限设置。
2. 确认没有其他程序独占设备。
3. 刷新页面后重新授权。
4. 优先使用 HTTPS 平台地址。
5. 麦克风仍不可用时，切换为文字回答。
6. 摄像头是可选功能，关闭后仍可完成面试。

### 7.2 AI 长时间没有回复

- 检查网络连接；
- 等待当前请求结束，不要连续重复发送；
- 刷新页面，系统会恢复已经保存的对话；
- 仍无响应时联系管理员检查 AI 服务配置。

### 7.3 报告一直显示“生成中”

- 报告由独立后台任务生成，繁忙时需要等待；
- 稍后刷新大厅或历史记录；
- 如果状态变为“报告失败”，单击“重试报告”；
- 多次失败时联系维护人员检查 Redis、报告 Worker 和 AI 服务。

### 7.4 无法开始新的面试

根据页面提示处理：

- 继续已有面试；
- 等待冷却倒计时结束；
- 先查看上一份报告；
- 等待上一份报告生成完成；
- 若状态明显异常，联系管理员。

### 7.5 成绩、榜单或能力雷达没有更新

只有报告生成完成的标准面试才会进入主要统计。请先确认报告状态为“已完成”，
然后刷新对应页面。

### 7.6 页面提示 403

当前账号没有该页面的权限。确认是否登录了正确角色；如权限配置有误，请联系
校级管理员，不要借用其他人的账号。

### 7.7 页面提示 503

系统暂时未就绪，可能是数据库迁移、Redis 或后台 Worker 异常。普通用户应
稍后重试；维护人员应检查就绪状态和服务日志。

## 8. 数据与隐私注意事项

- 不要在回答、简历或岗位描述中填写密码、验证码、密钥等敏感信息。
- 简历仅应填写真实经历，AI 优化结果必须由学生本人核对。
- 摄像头画面只用于面试过程中的单帧分析，本地预览不代表持续上传。
- 语音、临时文件和生成内容的保留时间由管理员配置。
- 教师和管理员只能将学生数据用于教学和授权管理目的。
- 不应在公共群聊中传播学生简历、报告、一次性密码或导入文件。
- 使用公共电脑后必须退出账号。

## 9. 系统维护人员快速检查

平台提供以下非敏感状态接口：

| 地址 | 用途 |
| --- | --- |
| `/healthz` | 检查 Web 进程和数据库连接 |
| `/readyz` | 检查数据库迁移和报告队列是否可用 |
| `/queuez` | 查看报告队列健康状态和积压概况 |

正常提供服务前，应确认：

1. `/healthz` 返回 HTTP 200；
2. `/readyz` 返回 HTTP 200；
3. 数据库迁移版本为 current；
4. Redis 可连接；
5. 至少有一个报告 Worker 在线；
6. AI 和语音服务所需环境变量已正确配置。

部署、数据库迁移、报告队列和测试命令请参阅项目根目录的 `README.md`。

## 10. 建议使用流程

学生建议按以下路径形成完整训练闭环：

1. 完善基础档案和求职简历；
2. 在知识充电站完成相关课程；
3. 使用随机问题面试进行单题热身；
4. 选择目标企业和岗位完成标准模拟面试；
5. 等待报告生成；
6. 阅读总评和逐题建议，完成复盘；
7. 针对薄弱维度继续学习或再次练习；
8. 条件允许时进入复面和终面；
9. 通过能力雷达和历史记录观察长期变化。

教师建议定期查看数据驾驶舱、学生名册、班级对比和薄弱题聚合，将平台结果
作为教学观察的一项参考，并结合课堂表现和实际任务综合评价学生。
