启用麦克风与摄像头

麦克风与摄像头默认需要 HTTPS 安全连接。Edge 的例外设置只在该浏览器生效，Chrome 和手机需要分别处理。

网页无法直接添加浏览器策略或打开浏览器内部设置。下方可复制设置所需地址，再手动完成设置。

  1. 把设置地址粘贴到浏览器地址栏并打开。
  2. 找到 “Insecure origins treated as secure”，在地址列表中追加上方本站地址，保留已有地址（多个地址用英文逗号分隔）。
  3. 设为 Enabled，点击 Relaunch 重启浏览器，再返回面试页面并允许麦克风、摄像头权限。重启会中断当前通话，请先完成本次回答。

此设置仅适合可信测试站点，不会加密 HTTP 连接。若此选项不存在、被管理员禁用或设置后仍不可用，请使用 HTTPS 地址。

由管理员统一配置策略

管理员可将本站地址加入 OverrideSecurityRestrictionsOnInsecureOrigin 策略，重启浏览器后生效。Chrome 与 Edge 的策略分别配置；受管理的 Android Chrome 可由设备管理员下发策略，普通手机网页无法自行安装。

正式使用请联系管理员配置带有效证书的 HTTPS 地址。现在也可以输入文字继续面试。
